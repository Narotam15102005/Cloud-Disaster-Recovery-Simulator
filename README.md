# Cloud Disaster Recovery Simulator

## 📖 Project Overview
This mini project simulates disaster recovery in cloud computing.  
It demonstrates how systems can recover after a failure such as a server crash.

## 🛠 Features
- Simulates a disaster scenario (e.g., server crash).
- Shows recovery steps (backup, restore, verification).
- Simple web interface built with Flask.
